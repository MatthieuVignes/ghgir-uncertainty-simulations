# Uncertainty propagation and attribution on a graphical model of a GHG inventory chain - preliminary simulations

**Status: proof-of-concept**

This repository accompanies a concept note submitted to MPI's Greenhouse Gas
Inventory Research (GHGIR) Fund, 2026/27 round, against
[Priority 5, "Monte Carlo analysis of the GHG inventory"](https://www.mpi.govt.nz/dmsdocument/70932-Greenhouse-Gas-Inventory-Research-Fund-202627-Priorities).
It exists to show, on a small and fully-inspectable structure, the
methodological point the concept note argues for: **representing an
inventory's dependency structure explicitly changes both the total
uncertainty estimate and the ranked attribution of uncertainty**, relative to
treating every input as independent.

## What this demonstrates

MPI's brief for Priority 5 asks applicants to (1) compare Monte Carlo against
alternative uncertainty techniques, (2) apply a full uncertainty
quantification, (3) identify and rank key contributors to uncertainty, and
(4) recommend how ongoing uncertainty analysis should be run. This repo
implements a minimal version of all four on the same toy structure:

| Script | What it does | Maps to |
|---|---|---|
| `R/dag_model.R` | Defines the toy DAG: 8 independent root uncertainty sources, forward equations to a national total | The "explicit dependency structure" the concept note proposes |
| `R/monte_carlo.R` | Correlation-aware Monte Carlo vs. a "naive" version that (wrongly) treats every input as independent | Objective 1 & 2, and the concept note's core critique of plain MC |
| `R/analytical.R` | Closed-form delta-method propagation, with a Fenton-Wilkinson log-normal approximation for the sum of correlated log-normal category emissions | Objective 1 (analytical error propagation) |
| `R/bayesian.R` | Bayesian updating (conjugate to avoid package installation) of the two shared latent nodes on synthetic "calibration" observations, then posterior-predictive forward propagation | Objective 1 (Bayesian methods) |
| `R/attribution.R` | Sobol (variance-based) first- and total-order sensitivity indices for all 8 root factors, via the Saltelli/Jansen pick-freeze estimator | Objective 3 (ranked, defensible attribution) |
| `run_demo.R` | Runs everything end-to-end and writes figures & a results summary | Full demo |

### Headline results (synthetic)

Running `run_demo.R` with the default toy parameters gives, approximately:

- Treating the two categories' shared pasture-quality and methodology-error
  terms as independent (the "naive" Monte Carlo/analytical approach)
  **understates the national-total uncertainty's standard deviation by
  roughly 10-12%** relative to the correlation-aware model.
- The analytical (delta-method / Fenton-Wilkinson) method reproduces the
  Monte Carlo standard deviation to within ~0.2-0.3% in this toy example. Its 
  moments are exact; only the tail/CI relies on a log-normal approximation.
- Conditioning the shared latent nodes on synthetic calibration data (a
  Bayesian step neither plain Monte Carlo, nor the analytical method can do)
  **narrows the total-uncertainty standard deviation by roughly 35-40%** .It 
  illustrates why a graphical structure is useful beyond propagation alone:
  data collected at one node can inform the whole graph.
- Sobol attribution ranks the shared **emission-factor/methodology** term as
  the largest single contributor to national-total variance, ahead of
  feed/DMI-side activity data and animal-numbers activity data. This ranking
  would not be visible from each input's own marginal variance alone.

*(Exact numbers vary slightly with the random seed and print at the end of
`run_demo.R`; see `results/summary.txt` and `results/sobol_indices.csv`
after running.)*

```bash

```

(no extra R packages needed)

## Relationship to the full proposal

The concept note proposes scaling this approach up to AIM's actual category
and sub-model structure (with real activity data, emission factors, and
model-parameter uncertainty, sourced from MPI/AgResearch documentation and
the published technical papers cited in the concept note), and to formally
compare the three propagation methods and the attribution ranking on that
real structure rather than a toy one. This repository is offered only as
evidence that the proposed methodology is implementable, not as a preview of
its results on the real inventory.

## Important: this is entirely synthetic

- **No data from MPI, AIM, AgResearch, or any other real inventory source is
  used anywhere in this repository.** Every parameter (herd sizes, dry-matter
  intake, methane scale factors, uncertainty magnitudes) is an illustrative,
  hand-picked value chosen only to produce a plausible-looking demonstration.
- The national-total figures this code produces (order of ~1 million tonnes
  CH4/yr) are realistic **by design**, so the plots read sensibly, but they are 
  not estimates of actual NZ agricultural emissions or its uncertainty, and must 
  not be cited as such.
- The DAG structure (pasture quality → DMI → enteric methane → emissions,
  for two categories sharing a pasture-quality signal and a methodology-error
  term) is a deliberately simplified stand-in for AIM's much larger and more
  detailed category structure, chosen to be small enough to fully specify,
  audit, and explain in a few pages of code.
